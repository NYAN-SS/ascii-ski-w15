# ASCII SKI（改良版）

## ゲームの概要

Windowsのターミナル上で動作する縦スクロール型アクションゲームです。画面上から流れてくる木（`A`）や崖（`*`）を避けながら滑走し、走行距離とボーナスアイテムでスコアを稼ぎます。時間が経つにつれてスクロール速度が速くなります。

## 動作環境

- OS：Windows（VS Code 内蔵ターミナル / Windows ターミナル）
- Python：Python 3.x
- 必要なライブラリ：追加ライブラリ不要（Python標準ライブラリ `os`、`random`、`sys`、`time`、`msvcrt` のみ使用）

## インストール方法

1. リポジトリをローカルPCにダウンロード（または `git clone`）します。
2. プロジェクトフォルダーを開き、Python 3 がインストールされていることを確認します。追加パッケージのインストールは不要です。

## 起動方法

VS Code のターミナル（またはWindowsのコマンドプロンプト）でプロジェクトフォルダーに移動し、以下のコマンドを実行してください。

```bash
python ski_game.py
操作方法
← / → または A / D：滑走方向を左または右に切り替える

Space：ゲームの開始 / 一時停止（滑走中・停止中の切り替え）

R：リスタート（ゲームオーバー後やプレイ中のやり直し）

Q または Esc：ゲームを終了する

ルール・終了条件
滑走中は指定された方向へ自動的に移動し続け、距離（1ずつ増加）と得点（基本は 距離 × 10 にボーナス加算）が増えます。

ボーナスアイテム（+）に触れるとクラッシュせずに +50 点が加算されます。

木（A）、崖（*）、または左右の境界に接触するとゲームオーバー（X 表示）になり、R キーで再開できます。

追加・改良した機能
改良機能01：ボーナスアイテム（+）の追加とスコア加算
make_row でコース行を生成する際にボーナスアイテム（+）が一定確率で出現するようにしました。update_game の衝突判定を更新し、プレイヤーが + に触れた場合はゲームオーバーにならずにボーナス回数が増え、スコアに +50 点が加算されるようにしました。

スクリーンショット
現時点ではスクリーンショット未掲載です（ターミナル上の === ASCII SKI === 表示を確認済み）。

既知の問題・制限事項
最終課題の目標（3つ以上の機能追加・改良）のうち、現時点では1つ目の改良（ボーナスアイテム +）まで実装済みで、残りの追加機能は今後実装予定です。

msvcrt を利用しているため、Windows以外のOS（macOS / Linuxなど）では動作しません。

ターミナルのサイズが小さい場合や、ANSIエスケープシーケンスに非対応の環境では表示が崩れることがあります。
